# GAME

A high-quality multiplayer word game for mobile and web.

## Planned platforms

- Android
- iOS
- Web

## Planned core systems

- Letter / Human / Animal / Plant / Object / Country gameplay
- Real-time multiplayer
- Private rooms and matchmaking
- Accounts and profiles
- Scoring, XP, levels and leaderboards
- Anti-cheat and server-authoritative game state

## Architecture

The project will use TypeScript with Expo / React Native for the client and a dedicated Node.js real-time server.
